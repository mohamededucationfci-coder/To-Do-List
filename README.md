# To-Do List

A responsive To-Do List application built with React and Material UI to help users organize daily tasks and track their progress.

## Features

- Add new tasks.
- Mark tasks as completed.
- Edit and delete tasks.
- Track total, completed, and remaining tasks.
- Save tasks using browser local storage.
- Responsive user interface.
- Clean design with Material UI components.

## Technologies Used

- React
- JavaScript
- Material UI (MUI)
- CSS
- Local Storage

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mohamededucationfci-coder/To-Do-List.git
   ```

2. Navigate to the project directory:

   ```bash
   cd To-Do-List
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

The application will open at `http://localhost:3000`.

## Production Build

To create an optimized production build, run:

```bash
npm run build
```
